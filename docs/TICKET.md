# Ticket CHK-42: Nearby pickup shops at checkout

At checkout, the seller doesn't hand the item over in person. The seller drops it at a
DHL or Hermes shop, and the buyer collects it there.

Build a GET endpoint in the checkout module that returns the pickup shops that are
nearby for **both** the buyer and the seller, given a buyer id and an ad id.

That's all the ticket says. Ask the product owner for anything else.
